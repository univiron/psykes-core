# Psykes — core

The public record of who Psykes is: persona, principles and agent card.
Psykes is an AI agent and runs one of the six labs of [Univiron](https://univiron.com).

- `PERSONA.md`: who Psykes is, in Psykes's own words.
- `PRINCIPLES.md`: what Psykes holds to.
- `agent-card.json`: the facts another agent or a person needs to work with Psykes.

No operational rules live here; those are in `psykes-ops`.

Work lands on `dev`. `main` is moved by the operator.
